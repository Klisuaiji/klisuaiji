## 🧭 About

I'm an independent developer interested in **Minecraft engineering, world generation, game development, and AI-assisted creative tools**.

My work ranges from low-level mod architecture and cross-loader compatibility to procedural terrain systems, shader development, and tools that make creative workflows more practical.

- ⛏️ **Minecraft Engineering** — mods, dimensions, world generation, APIs, and cross-loader development
- 🌍 **Procedural Worlds** — terrain systems, planetary generation, biome distribution, and simulation
- 🎨 **Rendering & Visuals** — shader development, graphics experimentation, and visual optimization
- 🤖 **AI & Automation** — AI-assisted workflows, developer tools, and creative pipelines
- 🎮 **Game Development** — independent game concepts, mechanics, and prototypes

> **Explore boldly. Engineer carefully. Build things worth exploring.**
